# COVID-19 Ego-Network Behavioral Activation Study

## Project overview

Public health research study examining whether the Dunbar layer at which COVID-19 risk concentrates within an individual's social network predicts the speed and stage of behavioral activation along the Transtheoretical Model (TTM).

**Principal investigator:** Ben, Senior Healthcare Public Health Researcher, Kaiser Permanente
**Data collaborator:** Dr. Christian Lopez, Lafayette College (holds the COVID-19 Twitter dataset)
**Target output:** Peer-reviewed public health paper

## Core hypothesis

The *relational channel* through which risk information arrives — not just the volume of risk — predicts behavioral activation. Risk concentrated in inner Dunbar layers (closest 5 contacts) should trigger faster and stronger activation than equivalent risk in outer layers (150 acquaintances).

## Theoretical framework

- **Dunbar's Social Brain Hypothesis:** Human social networks organize into hierarchical layers: inner 5, middle 15, outer 50, outer 150, plus an ambient information layer (media/broadcast)
- **Transtheoretical Model (TTM):** Behavioral activation progresses through stages: Precontemplation → Contemplation → Preparation → Action
- **Four behavioral archetypes:** Ambient activators (~10-17%), Network-triggered (~50-55%), Resistant (~20-22%), Mixed sensitivity (~13%)
- **Fatigue** is modeled as a continuous modifier across all archetypes, not a separate type

## Pipeline architecture

Six sequential Python modules. Each reads CSVs from the previous step and writes CSVs with consistent naming. All file paths reference config variables at the top of each script.

Shared constants (PHASES, DUNBAR_LAYERS, etc.) and common helpers (date parsing, phase assignment, GoEmotions utilities) live in `pipeline_utils.py` to prevent drift between modules.

### File naming convention
All output files follow: `{descriptive_name}_{YYYY_MM_DD}.csv`
Input files from Dr. Lopez follow: `YYYY_MM_DD_HH_Summary_Details.csv` or `YYYY_MM_DD_HH_CT_Summary_Details.csv`

### Module sequence

1. **module_01_ego_candidates.py** — COMPLETE, validated, optimized for GPU cluster
   - Reads raw Summary_Details CSVs iteratively (chunk-by-chunk to handle 2.5B tweets)
   - Computes per-PersonID summary stats (tweet counts, interaction counts, phase activity, account metrics)
   - Outputs: ego_candidates_{date}.csv, ego_candidates_phase_activity_{date}.csv
   - **Optimization:** Vectorized date parsing (`pd.to_datetime` with format), vectorized phase assignment (`np.select`), `defaultdict`-based accumulation. Reviewed by Google Antigravity IDE for cluster performance.

2. **module_02_ego_filtering.py** — COMPLETE, validated against synthetic data
   - Reads ego_candidates CSV
   - Applies sequential filters: min tweets (>=20), temporal persistence (>=4 phases), unique reply targets (>=15), follower/friend ratio (<=50), retweet ratio (<=0.95)
   - Outputs: ego_list_{date}.csv (viable egos for network construction)

3. **module_03_interaction_extraction.py** — COMPLETE, validated, optimized for GPU cluster
   - Reads raw CSVs filtered to ego_list PersonIDs, writes edges to disk chunk-by-chunk
   - Extracts all interactions (replies, mentions, retweets) as directed edges
   - Outputs: interaction_edges_{date}.csv, interaction_summary_{date}.csv
   - **Optimization:** Iterative file processing with disk-flush per chunk, vectorized DataFrame construction instead of row-by-row iteration, `pd.to_numeric` with Int64Dtype for clean ID handling.

4. **module_04_dunbar_assignment.py** — COMPLETE, validated, GoEmotions integrated, optimized
   - Reads interaction_summary and interaction_edges CSVs
   - **Four relationship signals for composite tie-strength scoring:**
     - Signal 1: Interaction intensity — weighted combination of reply (W=3), mention (W=2), retweet (W=1) counts. Reciprocity bonus (1.5x).
     - Signal 2: GoEmotions-based linguistic intimacy — RoBERTa GoEmotions (SamLowe/roberta-base-go_emotions) classifies reply emotions. 28 emotions mapped to intimacy weights. When GoEmotions is disabled or unavailable, Signal 2 contributes zero.
     - Signal 3: Initiation balance — 1 - 2*|outbound_ratio - 0.5|. Perfectly balanced = 1.0.
     - Signal 4: Temporal consistency — phases_interacted / 5.
   - **Composite scoring:** `raw_intensity * (1 + W_INTIMACY * intimacy) * (1 + W_BALANCE * balance) * (1 + W_CONSISTENCY * consistency)`.
   - **Dunbar layer assignment:** Alters ranked by composite score per ego. Rank 1-5 = inner_5, 6-15 = middle_15, 16-50 = outer_50, 51-150 = outer_150, 151+ = beyond_150.
   - Outputs: ego_network_{date}.csv (14 columns), network_summary_{date}.csv

5. **module_05_risk_activation.py** — COMPLETE, validated, GoEmotions + seed-word-expansion integrated, optimized
   - Reads ego_network CSV + raw tweet data
   - **IMPORTANT: full_text field is a HARD BLOCKER.** Modules 4-6 require tweet text for GoEmotions, keyword matching, Word2Vec training, and TTM scoring. Without it, all risk and TTM signals will be zero. Ensure full_text is in the Lafayette extract before running.
   - **Part A — Risk density:** Three signals: keyword threat (W=0.6), sentiment shift from Phase 3 baseline (W=0.2), GoEmotions emotion risk ratio (W=0.2).
   - **Part B — TTM stage classification:** Seed-word-expansion grounded in Sacco et al. (2023). Seeds expanded via Word2Vec. GoEmotions reinforcement. Simple keyword approach kept as comparison columns.
   - **Part C — Latency measurement.**
   - Outputs: ego_phase_activation_{date}.csv, ego_latency_{date}.csv, ambient_risk_timeseries_{date}.csv

6. **module_06_statistical_analysis.py** — COMPLETE, validated
   - Reads Module 5 outputs
   - **Part A:** Mann-Kendall trend detection per ego per phase
   - **Part B:** Theil-Sen activation rate + Kruskal-Wallis group comparison + Dunn's post-hoc
   - **Part C:** OLS regression with ego fixed effects (demeaned within-estimator)
   - **Part D:** Random Forest classifier with leave-one-phase-out CV, Model A (full) vs Model B (ambient-only)
   - **Part E:** Cross-phase comparison synthesis table
   - Outputs: trend_analysis, slope_comparison, regression_results, confusion_matrices, cross_phase_summary CSVs

## Key design decisions

1. **Phase boundaries use genomic sequencing data, not policy actions.**
2. **Dunbar layer assignment uses four-signal composite scoring.**
3. **GoEmotions (RoBERTa) provides emotion-based classification** for intimacy (Module 4) and risk (Module 5). Cached to CSV for cross-module reuse.
4. **TTM classification uses seed-word-expansion** grounded in Sacco et al. (2023). NOTE: Seeds skew toward vaccination-specific language. Team should review for broader COVID behavioral domains.
5. **Risk density combines three signals:** keyword (W=0.6), sentiment shift (W=0.2), GoEmotions emotion risk ratio (W=0.2).
6. **Fatigue is a continuous modifier, not an archetype.**
7. **The ambient risk signal** is modeled separately from network risk.
8. **Code is developed locally, deployed to Lafayette.** All scripts self-contained with configurable paths.
9. **Module 6 uses non-parametric statistics** — all analyses per-phase first, cross-phase comparison as interpretive layer.
10. **Shared code lives in pipeline_utils.py** — phase definitions, date parsing, GoEmotions helpers centralized to prevent drift.
